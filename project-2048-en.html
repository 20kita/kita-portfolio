About the project

A mobile puzzle game inspired by 2048: slide the tiles and merge two of the same into the next one. I built it with HTML, CSS and JavaScript without any frameworks, and then turned it into an Android app with Capacitor.

The game has three free modes (Classic, Animals and Fruits), 11 unlockable themes, three board sizes (3×3, 4×4 and 5×5), and daily and weekly missions that give diamonds. It also has smooth animations, sounds made in code (Web Audio API), light and dark mode, two languages and automatic saving after every move.
