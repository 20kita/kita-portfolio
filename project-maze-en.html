About the project

A maze game: get the key at the bottom of the board and bring it back to the start, past 20 moving enemies and a devil that chases you in the bottom corridor. The game has a start menu, pause, checkpoints, a timer and a saved best time.

I first wrote the game in Python (pygame) and then rebuilt it step by step: I cleaned up the code and added a finish, a boss, a menu and a dark theme in the colors of this portfolio. Finally, I rewrote it in JavaScript (HTML Canvas) so it runs instantly in the browser.

Controls: arrow keys or WASD, P or Esc to pause. On a phone (best in landscape): drag your finger like a joystick and tap the top bar to pause.
