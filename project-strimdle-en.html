About the project

Strimdle is my own quiz website about Polish streamers from Twitch, Kick and YouTube. You read a quote, guess which of four streamers said it, and then watch the clip to check your answer.

The site has daily and weekly challenges, a leaderboard, playing with friends in private rooms (join with a code), and a form for adding your own quote, which goes into the game after I review it. There are already over 100 quotes, with new ones added every week. The site itself is in Polish, as it's made for the Polish streaming community.

How it was made

I took this project from an idea to a live website: I collected the quotes and clips, designed a clickable prototype in Figma for mobile and desktop, then built the site with a Supabase backend (user accounts, the quote database, scores) and deployed it on Cloudflare Pages.

The source code is private, but I'm happy to talk about it in an interview.
